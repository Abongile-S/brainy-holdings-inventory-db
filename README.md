# Brainy Holdings Inventory Management Database

## Overview
This project was developed as part of Belgium Campus Database Development 271/281 (2025).  
It addresses inventory tracking inefficiencies at Brainy Holdings, an IT, Security, and Solar company.  
The solution is a centralized SQL Server database that manages stock across multiple warehouses, customer orders, and job allocations.

## Features
- Entity Relationship Diagram (ERD) normalized to 3NF
- SQL Server implementation with tables, indexes, constraints
- Sample data population
- Queries for business insights (average pricing, discontinued items, warehouse distribution)
- Stored procedures, triggers, and views for automation
- Security setup with mixed‑mode authentication
- Full database backup
